# AI Markets Analyst — как получить ссылку для телефона

Приложение — `app.py` (Streamlit). Оно читает ваши скиллы из `.claude/skills/` при каждом запуске,
поэтому правите скилл в VS Code → `git push` → в вебе уже новая версия.

## 1. Ключ Anthropic API (5 мин)

1. https://console.anthropic.com → **API Keys** → Create Key. Скопируйте `sk-ant-...`.
2. **Billing** → пополните баланс (от $20). Подписка Claude Pro/Max к API **не относится**, это отдельный счёт.
3. **Limits** → поставьте месячный лимит расходов (например $50) — это главная защита от перерасхода.
4. Убедитесь, что в настройках организации включён **Web search** (иначе отчёты будут без данных).

## 2. Залить проект на GitHub (5 мин)

В VS Code с открытой папкой `AI-ME-Research-Tool`:
1. Слева **Source Control** (Ctrl+Shift+G) → **Publish to GitHub** → выберите **Private repository**.
2. Проверьте на github.com, что в репозитории есть папка `.claude/skills` (скрытые папки тоже должны загрузиться).

`.gitignore` уже не пускает в репозиторий секреты и ваши локальные `TRADE-*.md`/PDF.

## 3. Развернуть на Streamlit Community Cloud (бесплатно, 5 мин)

1. https://share.streamlit.io → войти через GitHub.
2. **Create app** → *Deploy a public app from GitHub* → ваш репозиторий, ветка `main`, файл `app.py`.
3. Придумайте адрес, например `egor-trading.streamlit.app`.
4. **Advanced settings → Secrets** вставьте:

   ```toml
   ANTHROPIC_API_KEY = "sk-ant-..."
   APP_PASSWORD = "придумайте-код"   # уберите строку, если нужен доступ без кода
   DAILY_LIMIT = 30                  # максимум отчётов в сутки на всё приложение
   # MODEL = "claude-sonnet-5-5"     # по умолчанию; для дешёвых быстрых отчётов: "claude-haiku-5-5"
   ```
5. **Deploy**. Первая сборка 3–5 минут. Ссылку можно отправлять.

На телефоне: открыть ссылку → «Поделиться» → **«На экран Домой»**, и она будет выглядеть как приложение.

## Как это работает

- Два раздела: **Акции** (скиллы `trade-*`) и **FX и макро** (`fx-*`, `macro-*`). Новый скилл появится в вебе после добавления строки в `COMMANDS` в `engine.py`.

- Пользователь выбирает команду и тикер → сервер запускает соответствующий `SKILL.md` через Claude API с веб-поиском.
- `trade-analyze` и `fx-analyze` идут как в скиллах: сбор данных → 5 агентов параллельно → синтез. Любой скилл со структурой PHASE 1/2/3 и блоками `#### Agent N` запускается так же.
- Отчёт открывается на странице, плюс кнопки **PDF** и **Markdown**. У каждого отчёта своя ссылка `?job=...`:
  можно заблокировать телефон и вернуться, а можно переслать.
- Один и тот же запрос (команда + тикер + язык) в течение 6 часов отдаётся из кэша бесплатно.

## Стоимость и ограничения

- Ориентир на Sonnet: Quick ≈ $0.1–0.3, одиночный скилл ≈ $0.3–0.8, полный Analyze ≈ $1–3 (внизу каждого отчёта показана оценка).
- Время: 1–3 минуты, Analyze до ~6 минут.
- Бесплатный Streamlit засыпает без посещений (просыпается за ~30 сек при заходе), а при перезапуске стираются старые ссылки на отчёты.
- Новый API-аккаунт имеет низкие лимиты скорости. Если Analyze падает с `rate_limit`, добавьте в Secrets `MAX_PARALLEL = 1` или пополните баланс до следующего уровня (tier).
- В вебе нет Alpha Vantage, все данные берутся из веб-поиска. `trade-report-pdf` встроен как кнопка PDF.

## Локальный запуск (для проверки)

```powershell
pip install -r requirements.txt
mkdir .streamlit  # если нет
# создайте .streamlit\secrets.toml с ANTHROPIC_API_KEY = "sk-ant-..."
streamlit run app.py
```
PDF локально на Windows требует GTK для WeasyPrint; если PDF-кнопка пишет ошибку, ничего страшного, на Streamlit Cloud всё ставится само из `packages.txt`.
